Privacy Architecture

The card game is only the demonstration. The core foundation is the cryptographic boundary separating public verification from private player state.

Core Protocol

Selective Disclosure Boundary

FairProof isolates what verifiers need to confirm fair play from what must remain private to preserve gameplay integrity.

Public State
  • Ruleset ID
  • Commitment SHA-256 Root
  • Played Move
  • Validity Assertion
  • Public Receipt Digest
Private State
  • Unplayed Hand Cards
  • Secret 128-bit Salt
  • Opponent Hand
  • Player Strategy
Next-Gen Blockchain

Midnight & Compact Mapping

How FairProof's browser-level commitments map directly to Midnight's zero-knowledge Compact smart contract primitives:

1. Local Ledger State (Commitment)

On-chain ledger stores only player_commitment: Bytes<32> without disclosing private hand elements.

2. Compact Witness Circuit (Assertion)

The client witness proves private knowledge of hand and salt satisfying the commitment root and move membership.

3. Public Transition (Settlement)

Upon valid circuit execution, the contract accepts the move, mutates the public match ledger, and issues an immutable receipt.
