# Demo Script

## 60-Second Walkthrough

1. Open the FairProof dashboard.
2. Show the SDK Flow panel and explain that a private hand is committed before any move is played.
3. Point to the Public vs Private panel.
4. Select a card from the private hand.
5. Click `Generate Proof`.
6. Show the public proof receipt: ruleset, commitment, played card, proof hash, and valid result.
7. Click `Resolve Round`.
8. Show the match history entry.
9. Click `Invalid Proof Example`.
10. Explain that a forged card is rejected because it is not part of the committed private hand.
11. End by showing `docs/midnight-mapping.md` and explain that Wave 2 moves commitments and receipts to Midnight.

## Key Message

FairProof proves the rule was followed without revealing the full hand or requiring invasive anti-cheat surveillance.
