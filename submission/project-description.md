# Project Description

FairProof SDK is a privacy-preserving rule verification toolkit for competitive games.

The project helps game developers verify that player actions followed the rules without exposing hidden game state or collecting invasive anti-cheat telemetry. The Wave 1 prototype includes a playable card battle demo, a browser-based SDK, commitment generation, valid and invalid proof examples, match history, and public proof receipts.

FairProof is designed for games where hidden information matters: card games, strategy games, turn-based games, on-chain games, and competitive games that want stronger fairness without unnecessary surveillance.

## One-Line Pitch

FairProof lets games verify fair play without revealing private cards, strategy, salts, or hidden match state.
