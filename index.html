Architecture Flow

How It Works

Four deterministic steps prove action validity without exposing player decks or strategies.

01 / COMMIT

Salted Commitment

Private state is hashed with a secret local salt to establish an immutable root hash before match start.

FairProof.commitHand()
02 / MOVE

Private Move

The player evaluates their move against the secret hand in local memory without broadcasting unplayed cards.

move = { card: "K-Hearts" }
03 / VERIFY

Rule Assertion

A compact circuit verifies that the played card belongs to the committed hand and conforms to match rules.

FairProof.verifyMove()
04 / SETTLE

Public Settlement

A tamper-evident receipt is published on-chain, proving fair play while keeping hidden cards confidential.

FairProof.createReceipt()

Developer API

Integrate in Minutes

Clean, simple API designed for rapid game studio adoption.

// 1. Initialize match and salted commitments
const match = await FairProof.createMatch({
  playerHand: [card1, card2, card3, card4, card5],
  opponentHand: opponentHand
});

// 2. Verify selected move against private commitment
const proof = await FairProof.verifyMove({
  ruleset: "card-battle-v1",
  privateHand: match.player.privateHand,
  salt: match.player.salt,
  commitment: match.player.commitment,
  move: { card: selectedCard }
});

// 3. Generate public receipt for on-chain/peer settlement
if (proof.valid) {
  const receipt = await FairProof.createReceipt({
    proof,
    round: 1,
    matchId: match.id
  });
  console.log("Verified Public Receipt:", receipt);
}
