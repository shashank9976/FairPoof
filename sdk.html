Match Lifecycle

FairProof.createMatch(options)

Generates salted state commitments for participating players and returns initial match state.

options.playerHand: Card[]

Array of private card objects representing player's initial hand.

options.opponentHand: Card[]

Array of opponent cards to initialize opponent's commitment hash.

options.ruleset?: string

Ruleset identifier (defaults to "card-battle-v1").

const match = await FairProof.createMatch({ playerHand, opponentHand });
Cryptographic Assertion

FairProof.verifyMove(payload)

Privately checks that a chosen card is owned by the player and that recalculation matches commitment.

payload.ruleset: string

Target game ruleset ID to evaluate against.

payload.privateHand: Card[]

Player's unrevealed hand kept securely in local memory.

payload.salt: string

Secret 128-bit hex salt generated at match initialization.

payload.commitment: string

Public SHA-256 root hash published at match start.

payload.move: { card: Card }

The specific card played for the current round.

const proof = await FairProof.verifyMove({ ...payload });
Selective Disclosure

FairProof.createReceipt(options)

Formats a public-ready cryptographic receipt stripped of all private salts and unplayed cards.

options.proof: ProofObject

Verified proof object returned by verifyMove().

options.round: number

Current round index within the match session.

options.matchId: string

Unique match identifier derived from player commitments.

const receipt = await FairProof.createReceipt({ proof, round: 1, matchId: match.id });
Security Primitive

FairProof.createReplayGuard()

Initializes an in-memory round-claim registry to prevent replay attacks or duplicate turns.

guard.claim(matchId, round): boolean

Claims a round turn. Returns true if fresh, false if replayed.

guard.has(matchId, round): boolean

Inspects whether a round was already claimed without mutating state.

const guard = FairProof.createReplayGuard();
