FairProof SDK

Small primitives for binding hidden state, checking actions, and publishing minimal proof receipts.

Open browser example
Core API

Verification lifecycle

createMatch()

Creates player commitments and shared public match state.

commitHand()

Binds a private hand to a salt-derived SHA-256 commitment.

verifyMove()

Checks ownership and commitment integrity without revealing the full hand.

createReceipt()

Returns a compact public record for the verified action.

Integration shape

Minimal usage

const match = await FairProof.createMatch({
  playerHand,
  opponentHand
});

const proof = await FairProof.verifyMove({
  ruleset: "card-battle-v1",
  privateHand: playerHand,
  salt: match.player.salt,
  commitment: match.player.commitment,
  move: { card: playerHand[0] }
});
